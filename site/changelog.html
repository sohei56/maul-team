What's new

Every release of MaulTeam.app, written so you can follow along even if you have never used it.

First time here?

Maul Team hands your coding project to a small team of AI agents that work the way a software team does: they plan a round of work, build it, review each other's code, and show you the result. You stay the Product Owner — you decide what gets built and whether it is good enough. It runs as a Mac app, or as a single command in your terminal.

Sprint
One round of work with a fixed goal. The team plans it, builds it, then shows you what it made.
PBI
A single item on the to-do list — “add a login screen”, “fix the CSV export”.
Scrum Master · Developer
The AI roles. One coordinates and keeps the plan on track; the others write the code and review each other's work.
The framework
The free, open-source engine that runs the team. The Mac app ships with it built in — so app updates also change how the team behaves.

August 2, 2026 · v2.0.7 Latest New

Tabs for every project — and a tap on the shoulder

Run several projects side by side and switch between them like browser tabs. And when the team is waiting on an answer from you, the app now tells you — instead of waiting in silence.

  • Tabs for running projects. Every project with a live team shows up as a tab at the top of the window. Click to switch; the others keep working in the background. The × stops a project's team — after asking you first.
  • You'll know when you're needed. When the team asks you a question or waits for a permission, that project's tab shows an orange badge — and if you are looking at another tab, a macOS notification appears with the actual question. Click it to jump straight there.
  • Long-running projects open fast again. A project that had accumulated months of to-do history could take minutes to open. The same check now runs in one pass — a project we measured went from nearly four minutes to five seconds.
  • No more silent overnight stalls. In rare cases the team could freeze waiting for a message that never arrived — and stay frozen until you came back. The cause is fixed, and a supervisor now checks every ten minutes and restarts any work that has actually died.

July 20, 2026 · v2.0.6 New

Reviews that finish the job

When the team reviews its own code at the end of a Sprint, it now clears out a whole class of problem at once — instead of turning up the same kind of mistake again the following week.

  • One report, every occurrence. If the review finds a mistake in one file, it now searches the rest of the project for the same mistake and lists every place it appears. The task is not finished until all of them are — so the same issue stops coming back Sprint after Sprint.
  • Documentation fixes, bundled. Small “this comment is out of date” findings used to become dozens of separate to-do items that crowded out real work. They now arrive as one item.
  • This site speaks Portuguese — eight languages now.
  • License wording now leaves room for a paid Enterprise plan later on. Nothing changes today: the framework stays free and open source, and the app stays free to use.

July 18, 2026 · v2.0.4 New

The app updates itself

From this release on, MaulTeam.app finds new versions and installs them for you. No more downloading a disk image by hand.

  • Automatic updates. With your permission on first launch, the app checks for updates and installs them on its own, and every download is signature-checked. It delivers future releases, so this one still has to be installed the old way — one last time.
  • A real editor, built in. The file editor inside the app was rebuilt from scratch, with proper syntax colouring. It now opens in its own window, so you can keep it next to the terminal.
  • View options for that editor, including indent guides.
  • macOS 14 (Sonoma) or later. The app has needed this since the previous version — now the site and the README say so.

July 17, 2026 · v2.0.3 Fixed

The update that wasn't arriving

Some projects kept running an old copy of the team's engine even after you updated the app — silently, with no error message. This release fixes that, and adds checks so it cannot happen quietly again.

  • The bug. If the app was installed in a folder whose name contains a space — which is exactly where macOS puts it by default — part of the update did nothing at all. Everything now installs correctly no matter where the app lives.
  • A safety net. Every launch now reinstalls the engine files from scratch, brings your project's saved data up to the current format, and records which version it installed — so a mismatch shows up instead of hiding.
  • What to do. Install this version and reopen your project. The next launch syncs everything.

A friendlier first five minutes

July 15, 2026 · v2.0.0 First release

Maul Team, now a Mac app

The first public release of MaulTeam.app — the AI Scrum team in a native Mac window, instead of a terminal you have to set up yourself.

  • One window, the whole team. Talk to the Scrum Master in a built-in terminal on one side. On the other, a dashboard shows how the Sprint is going, what is on the to-do list, and what each agent is doing right now.
  • Opens without warnings. The download is signed and notarized by Apple, so macOS lets it run straight away.
  • Install it by downloading the disk image, or with brew install --cask maul-team.
  • You will need macOS 14 (Sonoma) or later, plus Claude Code, Python 3.9+, tmux and git.
